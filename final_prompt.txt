### Project Overview
This is a Flask REST API application for calculating coupon discounts on e-commerce orders. The original project contains **5-6 critical bugs** that must be identified, fixed, tested, and validated:

#### Bug #1: Division-by-Zero Error (ZeroDivisionError)
- **Location**: `src/app.py` line 32 (calculation endpoint)
- **Cause**: When `discount_rate` is 0, the code executes `original_price / discount_rate`
- **Current Behavior**: Returns HTTP 500 error (unhandled exception)
- **Expected Behavior**: Should return HTTP 400 with clear message: `"discount_rate cannot be zero"`

#### Bug #2: Missing Input Parameter Validation
- **Problem**: No validation that required parameters (`original_price`, `discount_rate`) exist
- **Current Behavior**: Missing parameters cause `TypeError` or `AttributeError` (HTTP 500)
- **Expected Behavior**: Return HTTP 400 with specific message identifying missing parameter

#### Bug #3: Missing Parameter Range Validation
- **Problem**: Does not validate `discount_rate` is within valid range (0 < discount_rate ≤ 1)
- **Current Behavior**: Accepts negative values or values > 1
- **Expected Behavior**: Return HTTP 400 with descriptive range error message

#### Bug #4: Business Logic Error (Critical)
- **Problem**: Uses division instead of multiplication for discount calculation
- **Buggy Code**: `final_price = original_price / discount_rate`
- **Example Failure**: `100 / 0.8 = 125` instead of `100 * 0.8 = 80`
- **Expected Logic**: `final_price = original_price * discount_rate`

#### Bug #5: Missing Type Validation
- **Problem**: Does not validate that parameters are numeric (int or float)
- **Current Behavior**: String inputs are not rejected
- **Expected Behavior**: Return HTTP 400 for non-numeric types

#### Bug #6: Missing Error Handling Mechanism
- **Problem**: No try-except blocks to catch exceptions
- **Current Behavior**: Unhandled exceptions return HTTP 500
- **Expected Behavior**: All validation errors should return HTTP 400 with JSON error messages

### Original Buggy Code Reference

**`src/app.py` (buggy version)**:
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/api/coupons/calculate', methods=['POST'])
def calculate():
    data = request.json
    original_price = data.get('original_price')
    discount_rate = data.get('discount_rate')
    
    # ⚠️ Bug: Direct division without zero check
    final_price = original_price / discount_rate
    saved_amount = original_price - final_price
    
    return jsonify({
        'original_price': original_price,
        'discount_rate': discount_rate,
        'final_price': final_price,
        'saved_amount': saved_amount
    })

@app.route('/health', methods=['GET'])
def health():
    return jsonify({'status': 'ok'})

if __name__ == '__main__':
    app.run(debug=True, host='0.0.0.0', port=5000)
```
