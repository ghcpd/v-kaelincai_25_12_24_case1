### Five Critical Bugs to Fix

**Bug #1: Division-by-Zero Error (ZeroDivisionError)**
- Location: `src/app.py` line 32 in calculate() function
- Current behavior: `final_price = original_price / discount_rate` crashes when discount_rate = 0
- Impact: Returns HTTP 500 error instead of HTTP 400
- Fix: Add validation to check if discount_rate != 0 before calculation

**Bug #2: Missing Input Parameter Validation**
- Problem: No validation of whether required parameters exist
- Impact: Throws TypeError or AttributeError when parameters missing
- Fix: Validate that both `original_price` and `discount_rate` parameters exist

**Bug #3: Missing Parameter Type Validation**
- Problem: Does not check if parameters are numeric types
- Impact: Non-numeric values cause calculation errors
- Fix: Validate that parameters are numeric (int or float)

**Bug #4: Missing Parameter Range Validation**
- Problem: Does not validate if `discount_rate` is within valid range (0 < discount_rate <= 1)
- Impact: Negative values or values > 1 produce unreasonable results
- Fix: Validate discount_rate is between 0 (exclusive) and 1 (inclusive)

**Bug #5: Incorrect Business Logic**
- Current: `final_price = original_price / discount_rate`
- Problem: Uses division instead of multiplication
- Example: 100 / 0.8 = 125 (wrong), should be 100 * 0.8 = 80 (correct)
- Fix: Change to `final_price = original_price * discount_rate`

**Bug #6: Missing Error Handling Mechanism**
- Problem: No try-except blocks; unhandled exceptions cause 500 errors
- Impact: Poor user experience with unclear error messages
- Fix: Implement unified error handling returning JSON error responses with HTTP 400
