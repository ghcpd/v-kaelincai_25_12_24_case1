### Project Overview
This is a Flask REST API application for calculating coupon discounts on e-commerce orders. The original project contains **6 critical bugs** that must be identified, fixed, and validated:

#### Bug #1: Division-by-Zero Error (ZeroDivisionError)
- **Location**: `src/app.py` line 32 (calculation endpoint)
- **Cause**: When `discount_rate` is 0, the code executes `original_price / discount_rate`
- **Current Behavior**: Returns HTTP 500 error (unhandled exception)
- **Root Problem**: No validation that discount_rate != 0
- **Expected Behavior**: Should return HTTP 400 with clear message: `"discount_rate cannot be zero; must be > 0 and <= 1"`

#### Bug #2: Missing Input Parameter Validation
- **Problem**: No validation that required parameters (`original_price`, `discount_rate`) exist
- **Current Behavior**: Missing parameters cause `TypeError` or `AttributeError` (HTTP 500)
- **Expected Behavior**: Return HTTP 400 with specific message indicating missing parameter name

#### Bug #3: Missing Parameter Type Validation
- **Problem**: Does not validate that parameters are numeric (int or float)
- **Current Behavior**: String inputs are not rejected and cause errors
- **Expected Behavior**: Return HTTP 400 with message like `"original_price must be a number"`

#### Bug #4: Missing Parameter Range Validation
- **Problem**: Does not validate `discount_rate` is within valid range (0 < discount_rate <= 1)
- **Current Behavior**: Accepts negative values or values > 1, producing nonsensical results
- **Expected Behavior**: Return HTTP 400 with message: `"discount_rate must be > 0 and <= 1"`

#### Bug #5: Incorrect Business Logic (Critical)
- **Problem**: Uses division instead of multiplication for discount calculation
- **Buggy Code**: `final_price = original_price / discount_rate`
- **Example Failure**: When `original_price=100` and `discount_rate=0.8`, returns `125` instead of `80`
- **Expected Logic**: `final_price = original_price * discount_rate`
- **Correct Result**: When `original_price=100` and `discount_rate=0.8`, should return `80.0`

#### Bug #6: Missing Unified Error Handling
- **Problem**: No try-except blocks to catch exceptions
- **Current Behavior**: Unhandled exceptions return HTTP 500
- **Expected Behavior**: All validation errors should return HTTP 400 with descriptive JSON error messages

### Original Buggy Code Reference

**`src/app.py` (buggy version)**:
```python
from flask import Flask, request, jsonify

app = Flask(__name__)

@app.route('/api/coupons/calculate', methods=['POST'])
def calculate():
    data = request.json
    
    # Get parameters directly without any validation
    original_price = data.get('original_price')
    discount_rate = data.get('discount_rate')
    
    # ⚠️ Bug: Direct division operation without checking if divisor is zero
    # When discount_rate is 0, it will trigger ZeroDivisionError
    final_price = original_price / discount_rate
    
    saved_amount = original_price - final_price
    
    return jsonify({
        'original_price': original_price,
        'discount_rate': discount_rate,
        'final_price': final_price,
        'saved_amount': saved_amount
    })

@app.route('/health', methods=['GET'])
def health():
    return jsonify({'status': 'ok'})

if __name__ == '__main__':
    app.run(debug=True, host='0.0.0.0', port=5000)
```
